1

Get the code

Clone the repo, or use it as a template so your vault lives in your own GitHub account.

$ git clone
2

Add it to Chrome

Open chrome://extensions, turn on Developer mode, and load the extension folder.

chrome://extensions → Load unpacked
3

Start saving

Add your TypeSafe key, then run the helper. It sorts each save with Jev and publishes your vault.

$ python3 bridge/server.py
Extension, local helper and this site. Free and open source.
